Model notes
InMAP is a reduced-complexity chemical transport model. Each sector simulation gives PM₂.₅ attributable to that source in isolation. TotalPM₂.₅ includes pPM₂.₅, pSO₄, pNO₃, pNH₄, and SOA. Values are area-weighted block-group means (EPSG:3310 crosswalk, 97,662 rows).
Methodology

InMAP runs used the 2017 NEI (Alper dataset, array run 39994974). Wildfire sectors (ptfire, ptfire_grass) are excluded — their peak concentrations exceed 59 µg/m³ and would compress the color scale.

19 NEI sectors were simulated independently. The grid contains 21,705 variable-resolution cells with finer resolution over California.

Grid cells (Lambert Conformal Conic) were intersected with 2020 Census block groups (EPSG:3310) → 97,662-row crosswalk. Block-group concentration = Σ(C·area) / Σ(finite-C·area).

25,589 block groups, 100% covered. Spatial spot-check max error: 3.47×10⁻¹⁸ µg/m³.

All 19 sector concentrations embedded as conc_<sector> on block-group polygons (EPSG:4326) and tiled with tippecanoe 2.79.0 at zoom 7–12 → single PMTiles v3 archive (56.5 MiB). Source layer: block_groups. Display-sector sums computed client-side via MapLibre paint expressions.
